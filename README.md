### Focus

- **AI Native 全栈交付：** 从 PRD / 原型到前后端联调、预览部署与验收，独立把产品推上线。
- **交易与履约工程：** 拼团状态机、订单与支付边界、幂等与失败回滚等真实业务判断。
- **Agent Skills & Harness：** 把协作沉淀为可复用 Skills 与交付门禁，让 AI 产出可复现、可验收。
